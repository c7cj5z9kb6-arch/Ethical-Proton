The non-judgemental fork of NotProton. No gatekeeping. No lectures. No pulling the ladder up behind you.

Ethical-Proton was created with a simple philosophy: Mac gaming should be about making games work, not policing how other people choose to play them.
We believe that:
- People shouldn't be shamed for exploring affordable gaming solutions.
- Developers shouldn't pull the ladder up behind them once they've found something that works.
- Open-source software should encourage experimentation, collaboration and accessibility.
- Discussions about alternatives to CrossOver shouldn't be silenced or banned from communities like Reddit simply because they involve competing software.
- Mac gamers deserve choices, not lectures about which tools they're allowed to discuss or use.

We're here to improve compatibility, not judge the people using it.

Ethical-Proton is an independent fork of NotProton, built around the belief that better Mac gaming comes from openness, experimentation and giving users more options.

The aim is straightforward: make Windows games easier to run through Steam on macOS, with CrossOver compatibility at the heart of the project.

Ethical-Proton is independently developed and is not affiliated with or endorsed by the original NotProton developers or CodeWeavers.
